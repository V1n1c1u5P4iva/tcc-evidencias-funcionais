
# Evidências Experimentais — TCC

Este repositório reúne as evidências da avaliação
de sistemas de gerenciamento de tarefas gerados
pelos modelos Claude e DeepSeek, utilizando
as estratégias Zero-shot e Chain-of-Thought (CoT).

## Objetivo

Disponibilizar registros dos testes de corretude
funcional e gráficos da análise estrutural
apresentados na monografia.

## Sistemas avaliados

- Claude — Zero-shot
- DeepSeek — Zero-shot
- Claude — Chain-of-Thought
- DeepSeek — Chain-of-Thought

## Testes funcionais

Foram aplicados dez casos de teste a cada
implementação, totalizando 40 execuções aprovadas
nos cenários avaliados.

Os testes contemplaram cadastro, autenticação,
operações de gerenciamento de tarefas e
restrições de acesso entre usuários.
